Laya · typed decisions

Give it a text and a question.
Get a decision back.

Laya never writes text. You send a state and a typed question — it answers with a choice, a yes/no probability, or a score, plus how confident it is. All questions run in one pass, locally, in under a second.

Pick the type that matches the decision you need. Sample outputs below are illustrations, not live results.

Choice

        
Pick exactly one option from a list you write. Each option has a short meaning that Laya reads.

Rate on a scale you define. Write the levels from lowest to highest; Laya returns a number on that scale.

Questions developers ask

    
Does Laya write text?
No. It never generates text. It reads your state and your question, and returns a typed decision: one of your options, a yes/no probability, or a number on your scale.

    
What does “confidence” mean?
How sure Laya is about that one answer, from 0 to 1. A low value is a good signal to send the case to a person instead of acting automatically.

    
Why does the wording of options matter?
Laya reads the question and each option’s meaning as part of its input. Clearer meanings give clearer decisions — try rewording an option and running again.

    
Can I ask several things at once?
Yes. Add up to 8 questions of any type; they are answered together in a single pass. The JSON tab shows every answer.

    
Is this the real model?
Yes. This page calls the Laya model running on this machine. The Result tab is a readable view of Laya’s answer; the JSON tab includes Laya’s own raw output, untouched.

    
How does the image option work?
Windows OCR turns the image into text, and that text becomes the state. Laya then answers your questions about the text — it is not a vision model.
